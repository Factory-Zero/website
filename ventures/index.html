Venture registry

Every venture, one foundation.

Every venture below is a company of its own, and they are built to run on each other: Cratefield is the framework, Colonizer runs the agents, Owlpost sends the mail, Ledgers keeps the books. The ones marked FZ stack are the foundation for the autonomous organization. Open a venture to see the problem it solves, what you can use today, and which of the others it uses; each page says which links are live and which are planned.
