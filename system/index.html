DESIGN PRINCIPLES

01

Every action is observable.

Agents write to a shared event log. Humans can replay, audit and reverse.

02

Permissions before autonomy.

An agent's authority is scoped per venture, per function, per budget. Autonomy levels raise the scope, never remove the boundary.

03

Ventures are tenants, not forks.

Improvements to the core reach every venture. Learnings from a venture flow back into the core.

04

No mystery.

The system is built from ordinary infrastructure, models and code. The novelty is in the coordination.
